# ニャーちゃん おせわゲーム

白いネコの **ニャーちゃん** をお世話する（ときどき妹の **ニューちゃん** も遊びに来る）、小さなお子さま（7歳くらい）向けの無料のブラウザゲームです。
ごはん・おふろ・あそび・ねんね・おしゃれのお世話や、おでかけをすると、ハートやシールがもらえます。失敗や罰はありません。

- 広告・課金・アクセス解析なし。個人情報は集めません（遊んだ記録は端末のブラウザの中だけに保存）
- 文字はひらがな・カタカナだけ。セリフはすべて読み上げます
- 一度ひらけば、インターネットにつながっていなくても遊べます（ホーム画面に追加するとアプリのように遊べます）

**遊ぶ**：https://yoshiaki99.github.io/nya-chan_care_game/ （公開の設定がすんだら、このアドレスで遊べます）

タブレット（iPad など）を横向きにして遊ぶのがおすすめです。スマートフォン（横向き）やパソコンでも遊べます。

## 保護者の方へ

画面左上の歯車を **2秒長押し** すると保護者メニューが開きます。

- 1日のプレイ時間の上限（15分／30分／なし）
- BGM・効果音の音量、読み上げのあり／なし
- ニューちゃん（妹）が遊びに来る：あり／なし
- げんきメーターの減り方（実際の時間／遊んでいる間だけ）
- オフラインで遊ぶ準備ができているか
- 最初からやり直す
- このゲームについて（プライバシー・権利の表示）

## 開発

仕様は [要件定義書_ニャーちゃんお世話ゲーム.md](要件定義書_ニャーちゃんお世話ゲーム.md) にまとめています。

### 手元で動かす

```sh
python3 -m http.server 8775
# ブラウザで http://localhost:8775 を開く
```

手元（http）で開いているときは、オフライン用の保存（`sw.js`）は使いません。

### 公開

`main` ブランチに入ると、GitHub Actions（`.github/workflows/pages.yml`）が GitHub Pages に公開します。
はじめて公開する前に、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。

公開の手順の中で、次のことを自動でします。

1. `node tools/check_lines.js` … ニャーちゃんのセリフが、すべて最後に「ニャー」で終わっているか・漢字が入っていないかを確かめる
2. `python3 tools/build.py --out _site` … オフライン用のファイル一覧（`sw.js` の `FILES` と `VERSION`）を作りなおし、公開するファイルだけを `_site` にそろえる（要件定義書・`tools/` などは公開しない）

### 道具（`tools/`）

| ファイル | すること |
|---|---|
| `build.py` | `sw.js` の一覧と、実際にある絵の一覧（`js/asset_list.js`）を作りなおす。`--out _site` で公開用のファイルをそろえる。**絵を足したり消したりしたら動かす** |
| `check_lines.js` | セリフの決まり（ニャーちゃんは最後に「ニャー」、ニューちゃんは「ニュー」・1回だけ・漢字なし）を確かめる |
| `make_transparent.py` | 白い背景の線画を、背景透過の PNG（1254×1254、足もとをそろえる）にする。`python3 tools/make_transparent.py 入力 出力.png` |
| `make_icons.py` | ホーム画面のアイコンと共有用の絵（`icons/`）を、基準画から作る |
| `check_svg.js` | ゲームの中で描く絵（SVG）に、同じ属性が2つ ないかを確かめる（あると 画像に したときに 何も うつらない） |
| `voice_samples.py` | 声の候補（ニャーちゃん・ニューちゃん）を作り、聞きくらべの ページ（`assets/voice_samples/聞きくらべ.html`）を作る |
| `make_voice.py` | えらんだ声で、ゲームの セリフ・名前を ぜんぶ 声にする（`assets/voice/`・`js/voice_clips.js`）。`--list` で 一覧だけ |
| `make_poses.js` | ニャーちゃんの表情6・動作6、ニューちゃんの3まいの絵（`assets/characters/nya_*.png`・`nyu_*.png`）を、基準画から作る。`node tools/make_poses.js`（Playwright が必要） |

Python の道具には `pip install pillow numpy scipy` が必要です。

### 声を つくる（Gemini TTS）

1. Google AI Studio で APIキーを 作り、手元の ターミナルで `export GEMINI_API_KEY=…` とする（キーは リポジトリに 入れない）
2. `python3 tools/voice_samples.py` … 声の候補を 作って、`assets/voice_samples/聞きくらべ.html` を 開いて えらぶ
3. えらんだ 候補の key を `tools/make_voice.py` の `VOICE`（`nya`・`nyu`）に 書く
4. `python3 tools/make_voice.py` … ぜんぶの 文を 声にする（1日の 上限に とどいたら、つぎの日に もう一度。`--lite` で 軽い モデル）
5. `python3 tools/build.py` を 動かしてから コミットする

m4a に するのに、Mac では `afconvert`、ほかでは `ffmpeg` を つかいます。

### ファイルの中身

```
index.html            ゲーム本体
css/style.css         見た目
js/character.js       ニャーちゃんの名前・絵・セリフ・顔や体の座標（キャラクターの設定は1か所に）
js/data.js            メーター・ごはん・リボン・ふく・メイク・アクセサリー・シール・絵のファイル名
js/character_nyu.js   ニューちゃん（妹）の名前・絵・セリフ
js/chara.js           ニャーちゃんの表示と動き
js/nyu.js             ニューちゃんの表示と、遊びに来る しくみ（1日1回まで・おへやに ときどき）
js/art.js, art_play.js  ゲームの中で描く絵（線画風の背景・アイテム・アイコン・あそびの道具）
js/art_outing.js      おでかけの絵（4つの場所の背景・タッチする道具・ドアのアイコン）
js/asset_list.js      実際にある絵・声のファイルの一覧（tools/build.py が作る）
js/assets.js          絵の読み込み
js/makeup.js          メイク
js/clothes.js         ふく（着せ替え）の絵
js/accessory.js       アクセサリー・みみの リボンの絵と、ふくも ふくめて 体に重ねて描くしくみ
js/audio.js           音楽・効果音（ファイルを使わず合成）
js/voice.js           読み上げ（声のファイルがあればそれを鳴らす。無ければブラウザの読み上げ）
js/voice_clips.js     文と声のファイルの対応表
js/state.js           自動セーブ（localStorage）
js/screens/*.js       各画面
sw.js                 オフラインで遊べるようにするしくみ（一覧は tools/build.py が作る）
assets/characters/    ニャーちゃんの絵（nya_reference.webp が基準画）
icons/                ホーム画面のアイコン・共有用の絵
```

### できていること・これから

| 状態 | 内容 |
|---|---|
| できている（第0段階） | ゲームのしくみ一式（ごはん8種・あそび9種・おしゃれ・シール・保護者メニュー・オフライン）、名前・保存名の入れかえ、セリフの入れかえ（すべて最後に「ニャー」）、基準画の背景透過、アイコン、公開のしくみ（GitHub Pages） |
| できている（第1段階） | 表情6・動作6・タイトル画（基準画から作る）、線画風の背景（おへや 昼・夜、おふろ）、くびのリボン（はじめは なし）、**着せ替え（ふく 11種・色えらび）**、メイク・アクセサリーの座標の調整 |
| できている（第1.5段階） | 妹の**ニューちゃん**が、ときどき（1日1回まで）おへやに遊びに来る：歩いて来て おしゃべり、なでるとハート、ときどき おみやげ、おへやに3回もどると帰る、「またね」で いっしょに手をふる |
| できている（第2段階） | ニューちゃんと いっしょに あそぶ（けいとだま・ちょうちょ・しゃしん）・おそろいの ふく、アクセサリーを 線画風に 描きなおし、こげ茶の わく線、あかるく はずむ BGM、声を つくる 道具 |
| できている（第3段階） | ごはんの入れかえ（**9種**：キャットフード・おみず・パフェ・ソフトクリームを 追加、チーズ・ミルク・クリームを はずす）、あそびの入れかえ（**5種**：けいとだま・ねこじゃらし・**ネズミの おもちゃ**・おえかき・しゃしん）、**おふろの作り直し**（バスタブに つかる・せっけん2つ〈ラベンダー・さくら〉・ニャーちゃんが じぶんで シャワー・おもちゃ4つ・タオル）、ねんねは **ベッド**で、おしゃれの見直し（リボンを **右耳・左耳**から えらぶ、メイクの シールを なくす、**ハートの コットン**、ふくは セーラーふくを 外して **ジャンパー・セーター・カーディガン**を 追加） |
| できている（第4段階） | **おでかけ**：おへやの ドア → おでかけの じゅんび（ふくを えらんで チェック）→ 行き先を えらぶ（**おまつり・ハロウィンパーティー・クリスマスパーティー・ニューちゃんの いえ**）→ その場所で 4つの ものを タッチして あそぶ → 「ただいま」。場所に あう ふく（ゆかた・おばけの マント・サンタの ふく など）だと ハートが ふえる。ニューちゃんが 来ていたら いっしょに いく |
| これから | ニャーちゃん・ニューちゃんの声を つくる（いまは ブラウザの 読み上げ。下の「声を つくる」） |

アイテム・ボタンのアイコンなどは、ゲームの中で描いた絵を表示します。画像ファイルを置けば差しかわります（置いたら `python3 tools/build.py` を動かす）。
